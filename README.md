# PyTorchEase

Unleash the potential of PyTorch with PyTorchEase: a harmonious fusion of simplicity and power, designed to illuminate the mathematical foundation of the PyTorch library.
## Overview

PyTorchEase is a lightweight and user-friendly deep learning library that simplifies the usage of PyTorch for various deep learning tasks. It provides intuitive abstractions and modules for building and training neural networks, allowing you to focus on your model and experiments rather than the implementation details.
## Features

- Lightweight and user-friendly deep learning library.
- Offers easy-to-use modules for common deep learning operations.
- Enhances understanding of the underlying mathematical concepts in PyTorch.

## Getting Started

1. Clone or download the PyTorchEase repository to your local machine.
2. Collect the files provided, including `linear.py`, `activation.py`, `loss.py`, and `tensor.py`, and place them in a directory of your choice.
3. In your Python script or notebook, add the directory containing the PyTorchEase files to your Python path or include it in your project.
4. Import the PyTorchEase modules as needed in your code to access the functionality. For example:
